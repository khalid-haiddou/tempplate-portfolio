CUSTOMIZATION
-------------

1. BRANDING:
   - Edit navbar brand: Line 27-30 in index.html
   - Change "GawsDev" to your name/brand

2. HERO SECTION:
   - Update title: Line 57-61 in index.html
   - Modify description: Line 62
   - Change statistics: Line 64-77
   - Update hero image: Line 94

3. ABOUT SECTION:
   - Edit bio text: Line 108-109
   - Update skills: Line 120-155
   - Change about image: Line 111

4. PORTFOLIO:
   - Add/edit projects: Line 167-260
   - Update images: Change img src URLs
   - Modify categories: Line 174-248

5. SERVICES:
   - Edit services: Line 270-313
   - Change icons: Line 277, 289, 301, 313
   - Update descriptions

6. CONTACT:
   - Update contact info: Line 332-341
   - Modify email/phone: Line 339, 344

7. COLORS & STYLING:
   - Edit CSS variables: assets/css/style.css (Line 5-24)
   - Primary color: --primary
   - Accent color: --accent
   - Background colors: --dark, --light
