Placeholder Images Directory

This directory is for storing your portfolio images.

The template uses placeholder images from via.placeholder.com for demonstration purposes.
Replace them with your actual images:

1. About section photo: Replace in index.html (line with "Your+Photo")
2. Portfolio project images: Replace the 6 project images in the portfolio section
3. Testimonial client photos: Replace the 3 testimonial images

Recommended image sizes:
- About photo: 300x300px (square)
- Portfolio images: 400x300px (landscape)
- Testimonial photos: 80x80px (square)

All images should be optimized for web use (JPEG or PNG format).
