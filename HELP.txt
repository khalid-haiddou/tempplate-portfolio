1. GETTING STARTED
------------------

Q: How do I use this template?
A: Simply open index.html in your browser or upload all files to a web server.

Q: Do I need to install anything?
A: No installation required. All libraries are loaded via CDN.

Q: Can I use this for commercial projects?
A: Yes, see LICENSE.txt for details.


2. FILE STRUCTURE
-----------------

Main Files:
  - index.html       : Main portfolio template (Modern design)
  - index-v2.html    : Alternative minimalist version

CSS Files:
  - assets/css/style.css    : Main stylesheet
  - assets/css/style-v2.css : Alternative version stylesheet

JavaScript:
  - assets/js/main.js  : Main functionality
  - assets/js/main-v2.js: Alternative version

Images:
  - assets/img/       : Place your images here


3. CUSTOMIZATION GUIDE
----------------------

CHANGING COLORS:
  Open assets/css/style.css
  Find :root variables (Line 5-24)
  Modify:
    --primary: #6366F1;      (Main brand color)
    --accent: #F59E0B;       (Accent color)
    --dark: #0F172A;         (Dark text)
    --light: #F8FAFC;        (Light background)


UPDATING CONTENT:
  Hero Section:
    - Line 57-61: Main title
    - Line 62: Description
    - Line 64-77: Statistics
    - Line 94: Hero image URL

  About Section:
    - Line 108-109: Bio text
    - Line 111: About image
    - Line 120-155: Skills list

  Portfolio:
    - Line 167-260: Project items
    - Update image URLs
    - Modify project titles and descriptions

  Services:
    - Line 270-313: Service cards
    - Change icons (Font Awesome classes)
    - Update service descriptions

  Contact:
    - Line 332-341: Contact information
    - Line 350-364: Contact form


ADDING PROJECTS:
  1. Copy a portfolio item block
  2. Add new image URL
  3. Update title and description
  4. Set data-category attribute
  5. Save and refresh


4. COMMON ISSUES & SOLUTIONS
-----------------------------

Issue: Images not loading
Solution: Check image URLs and ensure they're accessible
         Replace Unsplash URLs with your own hosted images

Issue: Styles not applying
Solution: Clear browser cache
         Check CSS file path is correct
         Verify Bootstrap CDN is loading

Issue: Animations not working
Solution: Ensure AOS library is loaded
         Check console for JavaScript errors
         Verify data-aos attributes are correct

Issue: Contact form not validating
Solution: Check form IDs match JavaScript
         Ensure main.js is loaded
         Verify form inputs have required attributes

Issue: Mobile layout broken
Solution: Check viewport meta tag is present
         Verify Bootstrap classes are correct
         Test responsive breakpoints


5. ADVANCED CUSTOMIZATION
--------------------------

ADDING NEW SECTIONS:
  1. Create HTML section with unique ID
  2. Add corresponding navigation link
  3. Style in CSS file
  4. Add animations with data-aos attributes


CHANGING FONTS:
  Edit Google Fonts link in <head>
  Update font-family in CSS
  Current fonts: Inter (body), Playfair Display (headings)


MODIFYING ANIMATIONS:
  Edit AOS initialization in main.js
  Adjust duration, delay, easing
  Add custom CSS animations in style.css


ADDING NEW PORTFOLIO CATEGORIES:
  1. Add filter button with data-filter attribute
  2. Update JavaScript filter logic if needed
  3. Set matching data-category on portfolio items

7. PERFORMANCE TIPS
-------------------

Optimization:
  - Compress images before uploading
  - Use WebP format for better compression
  - Minimize custom CSS/JS if possible
  - Enable browser caching
  - Use CDN for assets


Image Optimization:
  - Recommended size: 1200px width max
  - Format: WebP or optimized JPG
  - Use lazy loading for portfolio images


8. FAQ
------

Q: Can I remove the Bootstrap dependency?
A: Yes, but you'll need to rewrite responsive classes.

Q: How do I add more portfolio items?
A: Copy existing portfolio item HTML and update content.

Q: Can I use my own fonts?
A: Yes, replace Google Fonts link and update CSS font-family.

Q: How do I change the theme colors?
A: Edit CSS variables in :root section.

Q: Is this template SEO-friendly?
A: Yes, but add meta tags and optimize content for SEO.

Q: Can I use this with WordPress?
A: Yes, convert HTML/CSS to WordPress theme structure.

Q: How do I deploy to GitHub Pages?
A: Upload files to GitHub repository and enable Pages.

Q: What if I need more help?
A: Review the code comments and Bootstrap/AOS documentation.
